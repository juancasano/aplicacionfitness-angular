# Desarrollo Web — Ejercicios y prácticas

Repositorio de ejercicios del curso (HTML, CSS, JavaScript, APIs).

## Índice principal (abrir en el navegador)

**[Relacion.de.ejercicios.html](Relacion.de.ejercicios.html)** — listado con enlaces a todos los proyectos.

Con Live Server o un servidor local, abre ese archivo como punto de entrada.

## Estructura del repo

| Carpeta | Contenido |
|---------|-----------|
| `ejercicio1` … `ejercicio13` | HTML/CSS básico |
| `Flex/`, `Grid/` | Layout flexbox y grid |
| `Multimedia/` | Vídeo, galerías, formularios |
| `Responsive/` | Diseño responsive |
| `scripts/` | JavaScript (js1–js18, ecommerce, APIs, etc.) |

### APIs y Supabase (`scripts/`)

- [api-animales-supabase](scripts/api-animales-supabase/index.html) — CRUD animales y dueños
- [api-personas-supabase](scripts/api-personas-supabase/index.html) — CRUD personas
- Otras variantes: `api-personas-fetch`, `api-personas-async`, `ecommerce`, …
